# Shared implementation contract
Package dev.origin.ote. Models in core:model are the shared API; do not alter without notifying root.
Modules: :core:model (JVM), :engine:pack (JVM), :core:root (JVM), :data (Android), :engine:device (Android), :app (Android Compose).
Java17; Kotlin2.1.21, AGP8.10.1, Gradle8.11.1; compile/target36 min33. No shell code from input packs.
Root coordinator owns Gradle, AndroidManifest, engine:device, localization/resources integration and build.

Pack API in dev.origin.ote.pack: class PackCodec with importPack(input:InputStream, destination:File):ImportedTheme; exportPack(themeDirectory:File, output:OutputStream); readManifest(directory:File):ThemeManifest. Enforce ZIP traversal/duplicates/bombs/hash/PNG dimensions; no scripts.
Repository API in dev.origin.ote.data: class ThemeRepository injectable (Hilt). val themes:Flow<List<ThemeItem>>, history:Flow<List<OperationEntry>>, preferences:Flow<AppPreferences>; suspend import(uri:Uri):String; suspend importPngs(uris:List<Uri>,title:String,kind:ThemeKind):String; suspend importGif(uri:Uri,title:String,kind:ThemeKind):String; suspend export(id:String,uri:Uri); suspend delete(id:String); suspend favorite(id:String); suspend setPreferences(p:AppPreferences); suspend log(action:String,status:String,detail:String); suspend get(id:String):ThemeItem?; fun directory(id:String):File. Uses Room, DataStore, SAF. Native/raw ZIP support goes in repository if feasible; honest errors for unsupported.
Root API in dev.origin.ote.root: class RootManager; suspend probe():RootState; suspend execute(command:String, timeoutMs:Long=15000):RootResult; RootResult(exitCode:Int,stdout:String,stderr:String,timedOut:Boolean). No probe on startup. All command inputs shell-quoted; no remote code. UI may call only explicit button actions.
Device API coordinator: class DeviceEngine @Inject constructor(context,RootManager,ThemeRepository); fun deviceInfo():DeviceInfo; suspend compatibility():CompatibilityResult; suspend currentStatus():String; suspend apply(id:String):String; suspend backup():String; suspend restore():String. All writes only fixed verified fingerprint resource, current known hash or own journal. AOD integration unsupported explicitly until transaction design verified; AOD import/preview works. No fake apply success.
UI agent owns app/src/main/kotlin/dev/origin/ote/ui + app/src/main/res/values*/strings.xml and OteViewModel; includes actual navigation/dashboard/libraries/studio/root/settings, three styles, resource-only UI text. Coordinator owns MainActivity, application, manifest, DI wiring. UI receives OteViewModel via hiltViewModel; inject ThemeRepository, DeviceEngine, RootManager. No root auto-request.
